# dustdoc Documentation

This directory contains complete Markdown documentation for `dustdoc`.

## Documentation Index

- `getting_started.md`: build, install, and first runs.
- `cli_reference.md`: command-line behavior and exit semantics.
- `architecture.md`: module layout and processing pipeline.
- `extraction_rules.md`: doc comment extraction and item detection rules.
- `output_formats.md`: Markdown and HTML output generation details.
- `library_api.md`: public Rust API and data structures.
- `testing.md`: current tests and coverage profile.
- `known_limitations.md`: implementation limits and heuristic behavior.
- `developer_guide.md`: local workflow for maintainers.

## Scope

`dustdoc` reads Dust source files, extracts documentation comments, and emits documentation as Markdown or HTML.

This documentation reflects the current implementation in `dustdoc/crates/dustdoc/src`.
